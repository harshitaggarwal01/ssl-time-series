# ssl-time-series

Finance-informed self-supervised time-series encoder for the Stable Challenge.

The repository preserves the official evaluator and adds a compact training
package under `ssl_time_series/`. The model is trained only from the challenge
corpus. Stable Finance and GS Quant are used as methodological references for
causal returns, volatility, normalization, and multiscale features; neither
project supplies training data or pretrained weights.

## Quick start

```bash
uv sync
unzip corpus.zip -d corpus
uv run python -m scripts.profile_corpus --corpus corpus
uv run python -m scripts.train_encoder \
  --corpus corpus \
  --config configs/main.json \
  --output outputs/main.pt
uv run python -m scripts.export_model \
  --checkpoint outputs/main/step-020000.pt \
  --output outputs/model.onnx
uv run test_submission.py outputs/model.onnx
uv run python -m scripts.proxy_evaluate outputs/model.onnx
```

The corpus is large and should remain outside Git. `corpus_loader.py` memory
maps it; the training sampler never loads the concatenated values array into
RAM.

Training writes a resumable checkpoint every 500 steps by default and once
more at completion. Each run gets its own directory, with files named by step,
such as `outputs/main/step-000500.pt`. Set `--checkpoint-every` to change the interval,
or `0` to disable periodic saves. To continue from step 2,000 and train through
step 4,000, reuse the same architecture, feature groups, and seed:

```bash
uv run python -m scripts.train_encoder \
  --corpus corpus \
  --config configs/main.json \
  --steps 4000 \
  --resume outputs/main/step-002000.pt \
  --output outputs/main-continued.pt
```

The checkpoint restores the encoder, training heads, optimizer, loss history,
and random-number-generator state. The data-loader shuffle position is not
stored, so the resumed run may see windows in a different order.
Use a new `--output` prefix when branching from an earlier checkpoint to keep
the new run's step files separate from checkpoints already written.
Training output is shown in the terminal and appended to `train.log` in the
run folder by default; set `--log-file` to choose another path.

For a complete Google Colab workflow, open
[`notebooks/baseline_colab.ipynb`](notebooks/baseline_colab.ipynb). It clones
this branch, installs dependencies, downloads and extracts the official
corpus, trains the baseline, exports ONNX, runs the official checks, and
executes the proxy evaluation.

## Masked SSL track (`research/masked-ssl`)

Masked reconstruction plus a crop-view contrastive term, with untrained
spectrum and random-kernel features appended at export. The recommended
candidate is a 0.48M-parameter dilated convolutional encoder (6.65 MiB ONNX,
1,925 dimensions), included as
[`models/candidate-conv.onnx`](models/candidate-conv.onnx).

```bash
uv run python -m scripts.proxy_ucr --out eval_data/ucr        # UCR proxy set, evaluation only
uv run python -m scripts.train_mae --corpus corpus --output outputs/conv.pt \
  --arch conv --depth 8 --real-only --contrast 1.0 --view crop
uv run python -m scripts.export_model --checkpoint outputs/conv.pt \
  --output outputs/conv.onnx --pooling mean_std --fixed
uv run python test_submission.py outputs/conv.onnx
uv run python evaluate.py outputs/conv.onnx eval_data/ucr --out outputs/conv.ucr.json
```

Results and recommendations are in the
[Track 3 report](docs/reports/track3-masked-ssl.md); the same steps with a
short smoke-test option are in
[`notebooks/masked_ssl_walkthrough.ipynb`](notebooks/masked_ssl_walkthrough.ipynb).

## Implemented design

- Static evaluator contract: `[64, 1, 1024] -> [64, D]`.
- Per-window finite handling and normalization inside the model.
- Derived normalized level, difference, and magnitude channels.
- Compact patch transformer with LayerNorm and mean pooling.
- Scale, offset, noise, and contiguous patch masking augmentations.
- Masked reconstruction, multi-view contrastive, and next-step auxiliary losses.
- Deterministic series-level sampling and checkpoint metadata.
- ONNX export and synthetic proxy-task evaluation.
